# Form Test

Тестовий демонстраційний React 19 UI-проєкт для перевірки багатокрокової реєстрації, адаптивного дизайну, валідації форм і поведінки інтерфейсу без бекенду. Проєкт зроблений як навчальний або презентаційний інтерфейс, який імітує реєстрацію в системі з кількома етапами.

> Це тестовий демонстраційний проект. Він НЕ пов'язаний з офіційними державними сервісами, НЕ зберігає дані на сервері і НЕ надсилає їх в зовнішню систему. Не вводьте реальні персональні, медичні або конфіденційні дані.

## Що реалізовано

- 7-крокова реєстраційна форма
- покрокова валідація з використанням Zod
- індикатор прогресу та навігація між кроками
- збереження чернетки в sessionStorage
- фокус на першому невалідному полі
- інтернаціональні телефонні поля через react-phone-number-input
- перевірка email та форматів контактів
- фінальний екран успішної реєстрації з демо-реєстраційним номером
- генерація QR-коду після завершення реєстрації
- адаптивна секція з картками лікарів
- темний медичний/військовий UI стиль

## Запуск локально

```bash
npm install
npm run dev
```

Після запуску відкрийте адресу, яку виведе Vite, зазвичай:

```text
http://localhost:5173
```

Якщо порт зайнятий, Vite автоматично перевибере порт, наприклад:

```text
http://localhost:5174
```

## Логіка роботи форми

- дані вводяться покроково, а стан зберігається в React state
- валідація виконується окремо для кожного кроку
- після завершення кроку відмічається як пройдений
- якщо поля не заповнені або заповнені неправильно, користувачеві показуються помилки і фокус переміщується на перше проблемне поле
- на останньому етапі відображається підсумок введення
- після підтвердження генерується демо-реєстраційний номер і QR-код
- чернетка зберігається лише в поточній вкладці браузера через sessionStorage

## Особливості UX і доступності

У проєкті передбачено:

- чітку структуру форм і секцій
- семантичні `fieldset` / `legend`
- `aria-invalid`, `aria-describedby`, `aria-live`
- видимі стани фокусу для клавіатурної навігації
- адаптивну компоновку для мобільних пристроїв
- читаємий темний дизайн із контрастними кольорами
- окремі стратегії для телефонних полів і карток
